# anteform

**An AI-Native Execution Surface**

> AI prepares the context. Humans make the decisions.

**Project:** Anteform · **Manifesto:** Beyond Chat · **Research theme:** Execution Surface


**Anteform**は「前に」を意味するAnteとFormを組み合わせた名前です。人が作業を始める前に、AIが情報やインターフェースを使いやすい形に整える構想を表しています。

Anteformは、人が作業を始める前にAIが情報やインターフェースを適切な形に整え、人が状況を理解して判断し、成果を作れるようにすることを探る研究開発プロジェクトです。プロダクトは未公開で、性能に関する検証済みの主張はありません。実装は非公開です。
