# anteform

**An AI-Native Execution Surface**

> AI prepares the context. Humans make the decisions.

**Project:** Anteform · **Manifesto:** Beyond Chat · **Research theme:** Execution Surface


The name combines **ante** (“before”) and **form**: before work begins, AI prepares information and interfaces in a useful form for the person doing the work.

An early-stage research and development project exploring how software can prepare context and interfaces for human judgment and creation. This is not a released product, no performance claims have been validated, and the implementation remains private.
