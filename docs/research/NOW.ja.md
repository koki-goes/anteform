# 公開ロードマップ / 現在地

**現在の段階：構想整理と研究。** ここでは公開できる注力点を示し、内部の納期計画は掲載しません。

## 現在

- 問題、仮説、構想の境界を明確にする。
- コンテキスト、判断、制御、評価に関する研究課題を整理する。
- 方法や知見を安全に記録・公開する土台を整える。

## 研究で妥当性が確認できた場合の次段階

- 個別のインタラクション仮説を検証する、小規模でプライバシーに配慮した実験を設計する。
- 公開可能な方法、限界、結果を共有する。
- 根拠に合わせて構想を見直す。

公開日、機能の約束、性能目標は示しません。プロダクトと非公開実装は公開対象外です。
