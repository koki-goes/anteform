# GitHubプロフィール・個人サイト掲載文

## GitHubプロフィールのプロジェクト紹介

**Anteform — An AI-Native Execution Surface** — 人間の判断と創造のために、AIがコンテキストとUIをどう整えられるかを研究しています。初期段階のプロジェクトで、実装は非公開です。公開ノートでは問題設定、設計原則、共有可能な根拠を扱います。

## GitHubプロフィール向け短文

人が状況を理解し、判断し、成果を作るためのAIネイティブな仕事の場を研究しています。

## 個人サイト向け紹介文

人間の仕事のためのAIネイティブな実行基盤を研究しています。仕事の背景や重要な情報を把握し、自分で判断して納得できる成果を作るためのコンテキストとUIを整えるソフトウェアを探っています。プロジェクトは研究開発の初期段階です。研究課題や設計原則、共有可能な知見を公開し、非公開の実装や機微情報は公開資料に含めません。
