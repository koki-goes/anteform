# Issue と Discussion の運用方針

このリポジトリは公開研究の発信に使います。非公開実装やデータへのアクセスを必要としない範囲で、意見や貢献を歓迎します。

## Issue

文書の訂正、参考文献候補、公開資料のアクセシビリティ上の懸念、範囲の明確な研究課題など、具体的で区切れる項目に使います。可能な範囲で背景や根拠を添えてください。秘密情報、個人データ、非公開実装の詳細、機密報告は投稿しないでください。

## Discussion

仮説、研究課題、概念的な操作パターン、公開記事について広く意見交換する場です。個人の観察、仮説、研究による証拠のどれかを明記してください。

## メンテナーの対応

返信やIssueのクローズを保証するものではありません。公開範囲外の投稿はラベルを変更したり、クローズしたりする場合があります。貢献によって非公開計画や実装へのアクセス権が生じることはありません。貢献ガイドで募集していないコードやデータセットは投稿しないでください。
